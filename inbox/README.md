# Inbox

Drop raw planning documents here — the docs you and Claude write when you're expanding
an idea: prompts, project setup notes, a project CLAUDE.md, anything.

Files in this folder are **unprocessed**: they appear in the ledger's 📥 Inbox section
until an intake session turns them into a locked spec, at which point the original doc
moves to `projects/<slug>/spec/original/` and is preserved verbatim.

To process one, start a Foundry session and say: **"intake <filename>"** — or just
attach a new doc to any session and say "intake this".
