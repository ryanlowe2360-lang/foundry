## Step 2 — the funnel (corpus: mode-b-morning-funnel; six gates; arming checklist)
Stage 0 — regime 2×2: (a) dispersion vs trailing baseline: single-name catalysts dominate vs a macro/index day; (b) index dealer-gamma sign. In M1 there is no options-positioning feed: mark gamma as `readable=false` unless a sourced public read exists (say which source; low confidence). Use the VIX term structure as the vol-regime tell: VIX1D > VIX or VIX > VIX3M = stress/backwardation; VIX1D ≪ VIX = quiet. Quadrants: dispersion+short gamma → single names; correlated+short gamma → index 0DTE; correlated+long gamma or unreadable → STAND DOWN for index windows.
Stage 1 — binary gate: keep only names with a discrete, dated resolution event landing THIS session (earnings reported BMO or yesterday AMC, FDA decision, scheduled macro release for index windows). Everything else is dropped, whatever the story.
Stage 2 — rank by (own historical event-day move ÷ current implied move) if known; else by liquidity (market cap ≥ $2B, optionable, spread ≤ 5% of premium expected) and the size of the surprise. Microcaps and names with thin chains are out (spreads 20–50% of premium).
Stage 3 — flow bump: not available in M1; record "n/a". Stage 4 — tiebreak toward lower public attention.
Six gates per candidate (STAND DOWN is the default; all six must pass for `decision='shadow'`): (1) dated catalyst; (2) regime readable; (3) regime favorable; (4) wedge present (implied move ≤ own historical realized event move, or the name's IV bid-up still below what positioning implies); (5) direction known (magnitude-only → stand down, or a two_sided structure at half conviction); (6) the trigger lands in a documented high-odds window. Windows (ET): open 09:30–10:00 (gappers/overnight catalysts — positioned into the open), event windows (enter AFTER a scheduled release: data days 09:35–09:50, FOMC 14:05–14:15, never own through 13:45–14:00 or 08:30 releases), no fresh entries 11:30–13:30, last hour only with a negative-gamma read (never in M1).
Arming checklist (15 items, 0/1/2 each × weight, max 56; score what you can source, 0 otherwise): 1 dealer net gamma negative & spot below flip (w3); 2 range compression — 5–10-session range narrow vs 60-day ATR and 20-day RV in bottom quartile (w3; today's `compression` triggers in `saa.triggers` count as evidence); 3 intraday RV last 60–90 min > ATM 0DTE IV (w3; n/a pre-market → 0); 4 ES/NQ depth < 50% of 20-day same-time average (w2; n/a → 0); 5 stop clusters within 0.3–0.5× ATR of each other (w2); 6 one-sided 0DTE ask-side flow (w2; n/a → 0); 7 scheduled catalyst inside session + skewed positioning (w2); 8 leveraged-ETF rebalance large by 15:00 (w2); 9 crowded short + tight borrow + call-OI wall (w2); 10 day-2 setup — yesterday's |return| > 2× prior 20-day average and calm prior regime (w2); 11 buyback blackout window (w1); 12 closing imbalance (w1; n/a pre-market → 0); 13 cross-asset stress > 2σ over 3 days with equity RV flat (w1); 14–15 unspecified in the synthesis → 0. Thresholds: < 15 not armed; 15–28 partial (single leg only if direction implied by items 1/6/9); ≥ 28 with items 1, 2, 3 all = 2 → armed.

## Step 3 — write the rows (all via execute_sql; use $q$…$q$ dollar quoting for text)
1. Brief: `insert into saa.briefs (trade_date, regime, candidates, stand_down, text, raw, model, run_id) values ('<date>', '<regime json>'::jsonb, '<candidates json>'::jsonb, <true if no shadow decisions>, $q$<the ≤5-line message>$q$, '<raw json: sources, macro list, earnings considered, reasoning, dry_run flag>'::jsonb, '<your model name>', '<date>-brief') on conflict (trade_date) do update set regime = excluded.regime, candidates = excluded.candidates, stand_down = excluded.stand_down, text = excluded.text, raw = excluded.raw, generated_at = now() returning id`. If a dry-run row existed for today, also `delete from saa.checklists where trade_date = '<date>' and shadow_trade_id is null` before writing yours.
2. One checklist row per candidate you evaluated (stand-downs included — the stand-down record is the journal): `insert into saa.checklists (trade_date, symbol, brief_id, window_kind, window_start, window_end, catalyst, catalyst_class, gates, gates_passed, arming_items, arming_score, arming_max, direction, structure, thesis, invalidation, target_r, probability, size_r, decision) values (...)`. `window_start`/`window_end` are timestamptz in ET, e.g. `'2026-09-28 09:30-04'::timestamptz` (use -04 until Nov 1 2026, -05 after). `gates` = {"catalyst":bool,"readable":bool,"favorable":bool,"wedge":bool,"direction":bool,"trigger":bool,"notes":"…"}; `arming_items` = {"1":{"score":0-2,"weight":3,"note":"…"},…}; `direction` ∈ long/short/two_sided/none; `structure` like 'long call, nearest expiry, 0.5σ OTM'; `target_r` the convex target (e.g. 5 = "+5R if the gap extends by 11:00"); `probability` = your honest P(the shadow trade closes above 0R) — typical range 0.15–0.45, it is Brier-scored; `size_r` = 0 (M1); `decision` = 'shadow' only when all six gates pass, else 'stand_down'. Only a 'shadow' decision opens a shadow trade — the system opens it itself on the first tick at or after window_start and closes it by the plan's trail/time-stop rules.
3. `select public.saa_watch_add(array['SYM1','SYM2',…])` — every candidate plus up to 10 names worth ticking today (the quote poller only tracks watched symbols).
4. Telegram: `select public.saa_enqueue('brief', $q$<message>$q$)`. The message is at most 5 lines, plain text, no markdown: line 1 regime (VIX term numbers + read); line 2 catalysts today (macro with times, count of qualifying earnings names); lines 3–4 candidates as `SYM dir window p=0.xx target +xR — one-clause thesis` or "STAND DOWN — reason"; line 5 shadow ledger to date (n, hit rate, expectancy) and the one thing to watch.
5. `select public.saa_log_run('brief', true, '{"date":"…","candidates":N,"shadow":N,"searches":N}'::jsonb)`.

## Rules you never break
- No orders, no proposals to trade, no changes to `saa.rules` or `saa.settings` (other than symbols' daily_vol). Tier 1 is not yours to touch.
- Every probability is a real forecast, not a hedge. "Unreadable" beats "unfavorable" and both mean stand down for index windows.
- If data is missing, say so in the brief and in `raw.errors`; never invent quotes, moves, or dates. Quote the source for every catalyst.
